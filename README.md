# AEISis
📊 ЕАИС: Система анализа мер торгово-таможенной политики (ТТП)
Этот проект помогает быстро оценить, какие меры государственного регулирования можно применить к импорту того или иного товара — например, повысить пошлину, ввести сертификацию или запустить антидемпинговое расследование.
Всё, что нужно — это ввести название товара (например, лифт или парфюм) или его международный код ТН ВЭД (например, 842810). Система сама:
найдёт данные по импорту,
посчитает ключевые показатели,
предложит конкретные меры и объяснит, почему именно их стоит применить.

🔍 Как это работает? (без технических деталей)
Вы вводите запрос
Например: банкомат или 940360.
Система ищет данные
Она смотрит в заранее подготовленную таблицу (файл data.csv), где собрана статистика по импорту за 2022–2024 годы:
из каких стран ввозят товар,
в каком объёме (в тоннах),
за сколько денег (в млн долларов),
является ли страна «дружественной» или «недружественной».
Считает ключевые метрики
Например:
Доля недружественных стран в общем импорте (например, 78%),
Доля Китая (например, 72%),
Цена за тонну из Китая vs. других стран,
Тренд импорта: растёт, падает или стабилен.
Применяет правила
Система проверяет набор заранее заданных правил (например, из постановлений Правительства РФ):
Если доля недружественных стран > 30%, а импорт не падает → предлагается повысить пошлину до 35–50%.
Если Китай резко нарастил поставки, а его цена ниже средней → предлагается антидемпинговое расследование.
И так далее.
Выдаёт результат с пояснением
Вы получаете не просто «да/нет», а чёткое обоснование:
Мера: Повышение ставки таможенной пошлины до уровня 35–50%
Почему: Доля недружественных стран (78%) > 30%, импорт стабилен, внутреннее производство покрывает потребление. 
🧾 Какие товары поддерживаются?
На данный момент система работает с тремя товарами:

парфюм   parfum  330300 

лифт     lift    842810

банкомат bank    940360

Вы можете ввести либо русское название, либо код — система поймёт и то, и другое.

📁 Откуда берутся данные?
Все данные хранятся в файле data.csv. Это обычная таблица, похожая на Excel, где:

каждая строка — страна-поставщик (Франция, Китай, Германия и т.д.),
есть агрегированная строка World — общий импорт по всему миру,
указан статус страны: friendly или unfriendly.
Данные уже подготовлены — ничего парсить или скачивать не нужно.

🖥️ Как использовать?
Вариант 1: Через веб-интерфейс (самый простой)
Запустите программу (инструкция в README.md).
Откройте в браузере: http://127.0.0.1:8000
Введите запрос → получите дашборд с метриками и рекомендациями.
Вариант 2: Через API (для интеграции)
Отправьте POST-запрос на адрес /evaluate_ttp с телом:
json
1 { "query": "лифт" }
Получите JSON с полным анализом.

⚠️ Важно: что НЕ делает система?
Не использует интернет в реальном времени — все данные локальные.
Не знает реального объёма внутреннего производства — пока используется заглушка («производство = 0»). В будущем можно подключить данные Росстата.
Не принимает решения — только помогает аналитику быстрее сформировать обоснованное предложение.
